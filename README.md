## Оформление и данные

Предоставленная пользователем голубая фишка с белой короной используется в баннере и вместо флага. Происхождение и хеш оригинала сохранены в project.json. Все ресурсы оформления встроены в index.html; сеть нужна для обновления снимков, проверки кошелька и переходов по ссылкам.

Подтверждены успешными свопами два прямых пула STON.fi/TON и один DeDust/TON. Лента показывает подтверждённые покупки, продажи и сжигания. График: цена последнего наблюдавшегося свопа основного пула × текущий total supply; это не circulating market cap. Годовая история пополняется постепенно; неполное покрытие явно отмечается. Источники заморозки и стейкинга не настроены.

Общие метки: OG, Fragment +888, четырёхзначные .ton, сжигания. Сервисные атрибуции обновляются из Tonkeeper с источниками. Неизвестный адрес не получает выдуманного названия; проверка идентичности и меток выполняется постепенно. Чужие специальные DEV/NFT/стейкинг-правила не подключены.

## Сборка и обновления

```sh
python3 -m scripts.refresh_observatory
python3 build.py
python3 verify.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
```

Имеющийся validate.yml адаптирован к проверке созданного сайта. Тесты генератора относятся к исходному репозиторию шаблона (49 проверок прошли до создания); этот репозиторий выполняет 17 проверок сборщика и 15 JavaScript-проверок. Обновление через update.yml поддерживает workflow_dispatch и push исходников, сохраняет последние исправные секции и атомарно публикует snapshot.json и index.html в main. Регистрация живого внешнего Cloudflare-планировщика управляется отдельно; его исходный пример реестра не изменялся. Дополнительное расписание не добавлено.

Публикация в main не означает создание TON Storage bag. Отдельная загрузка в TON Storage в этой работе не подтверждена.
